# gentle-partitioner — Rust "particionador" that wraps gentle-shell in partitioned terminal panes

Branch `feat/gentle-partitioner` from `main@f4cc69a33`. New standalone Rust crate in `partitioner/`; the existing gentle-shell (Node/Pi) structure stays untouched and keeps running as the main engine inside its own PTY pane.
Architecture (research, L2-L3): reuse the proven agent-multiplexer stack (ratatui + crossterm + portable-pty + vt100, as in Herdr/Peemux) with our own code; translation pivot-through-English as a later engine; next-word prediction deferred (the LLM already predicts).

## Specs

- **S1 Stable core untouched.** "al estrucra que tiene actualmetne genlte sell es una estrucar estable, eso no me intera cambiarlo". The partitioner never modifies gentle-shell sources; it launches `gentle-shell` as a child process in a PTY.
- **S2 Rust supervisor first.** "quiero armar un motor mas grande tipo spark pero con rust, q se active priemro cunado se usa el comnado agenlte sell, este va aser el patricar". "tiene dos difnerets motores trbajando en paraleo y en hilos de concurerecina por eso rust, para que el usairo no tenga vision de trabas siemrpe trbajamo a bajo nivel". PTY I/O, input and render run on separate threads; the UI never blocks on the child.
- **S3 Each partition is its own terminal.** "cada particon es un render de otra termianl q se abre, para mejroa la expreicna del user". "vamos a manejra r los segmetnos como termianles separadas, pero visalmente se renderiza en un solo compente". "cuando se deba acutalziar una no esta aculzando todo la temrinal prnapl se acutal es una temianl con un fragmetno". Only changed cells are written to the real terminal.
- **S4 Sidebar.** "una seccion vertical q va a mostrar las carpetas archvios, formatos, tamanos cambios wroktree etc".
- **S5 Center viewer.** "una centra superio donde se abrirn los archivos al darle clic, es decir un user, selecciona un archvio, se le va abrir en el centro una ventana, que muesrta cmabios realizados, y va a poder esribri codiog direcatmete". "se ditinge en partion de dos, una dode a a pdoer editar manualme o escibri neuvo codiog y al lado el cmabnio q realizo los agente".
- **S6 Bottom chat.** "en la parte inferio es el chat tradicoenal con el que estamos trbajnod".
- **S7 Conditional layout + tool bar.** "este fragemteno solo se motrara cuando este en una caho detnermidnao, si no se va a se motrara uncametn el chat tal cual esta, pero una barra de vnagain latera con opcioen tool es decir el user quiere ver algo, por ejemplo la estruca de catpas un tool se desplgiu sbre todo y lo muestra".
- **S8 Translator engine (later phase).** "el otro motor es el traducrdo, es el que se va anecargar de envar una repstas en ingles en reciebral en ingle sy traducirla, el usario simpre la va a ver en su diamo nativo pero todo pasa por ingles".
- **S9 Prediction engine (deferred).** "tenemos un algoritmos, de enlace de palabra el mismo que usa gogole o meta para poder predecir una palabra, este es un motor". Research note: next-token prediction is what the LLM already does; deferred until a concrete use (e.g. local autocomplete) is decided.
- **S10 Mold, do not invent.** "yo nobusco invtar queiro es moldea lo que ya exite a una vs propia". "empzia a trbjar en el desarollo, para ir viendo mejoras, q podamos aplcair". Own code on the same crates Herdr/Peemux use; no fork.
- **S11 Do not hurt the experience.** "mejorar la experiencia de usario sin impactar el renderizado los recursos, la usabilidad". Idle loop does not repaint; redraw only on input, PTY output or resize.
